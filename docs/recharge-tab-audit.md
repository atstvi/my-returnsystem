# 충전(Recharge) 탭 재설계 노트

키워드: #생산성 #sns(x)st #mz20대여성st #세련 #깔끔 · 로즈 액센트/디자인 토큰 정합.

## 현황 (재설계 시작 시점)

- **충전 페이지**(`#page-recharge` → `.recharge-page`)
  - 히어로(💙 "괜찮아, 쉬어도 돼" + 시각)
  - 체크 카드(`.recharge-check-card` → `openRechargeCheck()`가 별도 `check` 페이지로 이동)
  - 에너지 카드(`.energy-card` / `.energy-levels`) — `goPage('recharge')` 시 `staminaMountEnergy()`가
    **공유 스태미나 슬라이더**(`stamina_level_v1`, 하루 0–100, 3밴드→routineCondition / 5밴드→recharge_energy)를
    마운트. `.energy-card-title`은 슬라이더가 뜨면 숨김. 사진 밴드(`stamina_photos_v1`)도 여기 반영.
  - 충전되는 것들 / 방전되는 것들(`#charge-items` / `#drain-items`) — `rcRenderList`, `+기록`(로그 패널),
    `편집`(`openActModal`).
  - 성찰(`.reflect-card`, `#reflect-ta`/`#reflect-list`, `saveReflect`) — "지금 진짜 필요한 게 뭐야?"
- **체크인 플로우**(별도 `check` 페이지, `#check-inner`) — 랜딩 → 4스텝(환경/상태/집중할 것/꺼내봐,
  `STEPS`) → 결과(`renderResult`: 내 입력 + AI 읽기 + 오늘의 다짐 → `saveResult`).

## 관찰된 개선점

1. **데스크탑 공간 낭비** — 좁은 1단 중앙 정렬(680px)이라 좌우가 텅 빔. 할일·타이머·루틴은 이미 구역화 풀블리드.
2. 에너지 UI가 충전 탭(스태미나 슬라이더)과 체크인 스텝(이모지 버튼)에서 다름 — 단, 슬라이더는 사진밴드
   기능이 있는 의도된 리치 컴포넌트라 함부로 통일하지 않음.
3. 충전 로그의 보상 뷰 부재(이번 주 충전 횟수/잔디), 에너지 추세 스파크라인 부재 — 후속 스코프.

## A. 데스크탑 구역화 (2단 레이아웃)

- `.recharge-body`를 폰=단일 컬럼 / 넓은 화면(≥880px)=2존 그리드로. **DOM/훅은 그대로**, 섹션들을
  `.rc-col`(좌·우) 래퍼로만 감쌈.
  - **좌(지금 나 상태)**: 체크 카드 · 에너지 슬라이더 · 성찰("지금 진짜 필요한 게 뭐야?")
  - **우(충전 활동)**: 충전되는 것들 · 방전되는 것들
- 각 `.rc-col`은 독립 flex 컬럼이라 높이가 독립(마조너리 느낌) — 그리드 행 정렬로 인한 빈틈 없음.
- 성찰을 좌측으로 옮겨 좌우 높이 균형 + "상태 확인→성찰→활동" 흐름. 폰에서는 체크→에너지→성찰→충전→방전.
- 히어로는 넓은 화면에서 상단 여백(`sp-16`→`sp-10`)만 줄여 두 컬럼이 접힘선 위로 오게.
- `max-width` 680→1080px, 좌우 패딩 `clamp(sp-6,4vw,sp-12)`.
- 스태미나 슬라이더·활동 로그·성찰 저장 로직 미변경. 제거된 컨트롤/훅 없음(8/8 유지). 가로 오버플로 0,
  라이트/다크/모바일 pageerror 0, `npm test` 32스위트 통과.

### 후속(다음 스코프)
충전 로그 주간/잔디 보상 뷰, 최근 7일 에너지 스파크라인, 체크인 결과·AI 읽기 화면 스캔성 개선.

## B. 체크인 결과 → 행동 연결

- 결과 화면(`renderResult`)에 `result-actions` 블록 추가(그리드와 다짐 카드 사이):
  - **✔ 오늘 집중할 것** — `answers.task1~3`를 칩으로 보여주고 `할일로 담기`(`checkinAddTasks`) →
    오늘 날짜(TK)·우선순위(high/mid/·)로 `tasks`에 추가 + `saveTaskData`.
  - **➜ 지금 할 수 있는 것** — `answers.reframe`를 `인박스로 담기`(`checkinAddReframe`) →
    `inboxItems.unshift({cat:'memo',unread:true})` + `saveInboxItems`.
- 버튼은 일회성(`.done`), 피드백은 앱 토스트(`showToast`)로 — 모달 아님. 답이 없으면 블록 미표시.
- 체크인이 성찰로 끝나지 않고 "체크인→행동" 루프로 이어짐(앱 철학). AI/저장 로직 미변경.
- 검증: 헤드리스에서 3칩+리프레임 렌더, 담기 시 tasks 3개(high/mid/·, 오늘)·inbox 1개 생성, 버튼
  일회성 처리, pageerror 0. `npm test` 32스위트 통과.

## C. 레이아웃 정리 (design-system 정합)

오너 피드백(실제 데스크탑 스샷): "전체 레이아웃 좀더 깔끔하고 실사용에 편리하게."
- **히어로** — 상단 중앙에 떠서 좌상단 공간을 낭비하던 블록을, 넓은 화면(≥880px)에서 **콘텐츠 폭에
  맞춘 좌측 정렬 컴팩트 헤더**(하트 아이콘 + 제목/부제 한 줄, 시각 우측)로 전환. 폰에서는 기존 중앙
  스택 유지. 하트 38px로 축소.
- **섹션 헤더 §3.9** — `💙 충전되는 것들` / `🔴 방전되는 것들`의 raw 이모지를 `.sec-ico` **SVG 라인
  아이콘**(충전=배터리+번개, 방전=저전량 배터리)으로 교체. `.section-label .sl-title`/`.sec-ico` 추가.
- **활동 카드 밀도** — `.activity-main` 패딩 `sp-6/sp-8`→`sp-5/sp-6`, 이모지 박스 44→40px로 살짝
  조여 에어리하게.
- 훅/로직 미변경(openActModal·hero-time·openRechargeCheck 등 4/4 유지). 가로 오버플로 0,
  라이트/모바일 pageerror 0, `npm test` 32스위트 통과.

## D. 위쪽 구조 수정 — 히어로를 좌측 존 헤더로 (오너 피드백 "위쪽 구조 망가짐")

- **문제**: C에서 히어로를 전체폭 밴드로 만들었더니, 인사가 좌측만 채우고 **우상단(충전 리스트 헤더 위)이
  텅 비어** 좌우가 비대칭 → 위쪽이 깨져 보임. 측정상 두 컬럼은 y118 동일 시작이나, 히어로 밴드가 위에
  얹혀 오른쪽이 빈 공간.
- **수정**: 히어로를 `recharge-body` 바깥 밴드에서 **`rc-col-left`의 첫 아이템**으로 이동. 데스크탑에서
  히어로(좌 인사)와 `충전되는 것들`(우) 헤더가 **같은 y에서 시작**(측정 y60=y60) → 좌우 균형, 빈 우상단
  제거. 히어로는 컬럼 내 컴팩트 좌측 행(하트 34px + 제목/부제 + 시각). 모바일은 소프트 워시 중앙 인사 유지
  (`@media(max-width:879px)`로 그라데이션·패딩 스코프).
- 훅 유지(hero-time 등). 가로 오버플로 0, 라이트/모바일 pageerror 0, `npm test` 32스위트 통과.
